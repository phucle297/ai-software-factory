# AISF project opt-in

- Load `~/.config/aisf/SESSION.md` for the shared session instructions, role assignment, and canonical policy paths. Read the referenced `PHILOSOPHY.md` before work; use `PROJECT_ONBOARDING.md` when onboarding is relevant.
- Keep shared configuration and role definitions in `~/.config/aisf/`, including its `agents/` directory. If the installation is missing, report that AISF must be installed rather than creating project-local copies.
- This section is the project's AISF opt-in. Removing it (or this file if it contains only AISF) opts new sessions out; do not recreate it without an explicit request. Removing instructions does not cancel already-running sessions or explicitly invoked AISF runner scripts.
